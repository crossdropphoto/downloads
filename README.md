## 安装说明

1. 下载 APK 到手机
2. 首次安装需允许"安装未知来源应用"(系统设置 → 安全/应用安装)
3. 升级版本时直接覆盖安装即可,数据不丢失

## 功能简介

- iOS ↔ Android 跨平台互传照片和视频(同一 WiFi 或热点直连)
- 原图无损传输,不压缩、不转码
- 实况照片(Live Photo)双向转换,动态画面完整保留
- 拍摄时间、GPS 位置随文件一起迁移
- 批量传输 + 局域网自动发现 + 扫码配对
